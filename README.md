# yadisk-dl

Консольная программа, которая скачивает папки с Яндекс Диска через официальный API. Грузит несколько файлов одновременно, показывает прогресс и при повторном запуске докачивает только недостающее.

## Зачем она нужна

Программа выросла из одного скрипта. Нужно было скачать папку на 390 фотографий. Веб-интерфейс Диска на бесплатном тарифе позволял скачивать только по одному файлу, а приложение для компьютера на этом аккаунте ничего не синхронизировало. Токен для API при этом работал, и скрипт на Python справился с папкой за несколько минут. Здесь он доведён до обычной утилиты с вопросами при запуске, полосой прогресса и тестами.

## Установка

Нужен Python 3.9 или новее.

```
pipx install git+https://github.com/unbrokenfounder/yadisk-dl
```

Если pipx нет, подойдёт обычный pip:

```
pip install git+https://github.com/unbrokenfounder/yadisk-dl
```

Из исходников:

```
git clone https://github.com/unbrokenfounder/yadisk-dl
cd yadisk-dl
pip install .
```

## Токен

Программе нужен OAuth-токен с правом читать Диск.

Самый быстрый способ: открыть https://yandex.ru/dev/disk/poligon/, нажать «Получить OAuth-токен» и скопировать результат. Этот токен открывает весь Диск, так что после скачивания его стоит отозвать в настройках Яндекс ID.

Аккуратнее будет зарегистрировать своё приложение на https://oauth.yandex.ru с правом `cloud_api:disk.read` и получить токен для него. Такой токен умеет только читать.

Передать токен можно через переменную окружения:

```
export YADISK_TOKEN='y0_...'
```

Если переменной нет, программа спросит токен при запуске, а вводимые символы не покажет. Параметра `--token` нет намеренно: аргументы остаются в истории оболочки и видны в списке процессов.

## Использование

Без аргументов программа сама спросит, что и куда скачивать:

```
$ yadisk-dl
Аккаунт: ivan
  1  Docs/
  2  Photos/
Что скачать? Номер из списка или путь на Диске (Enter: весь Диск): 2
Куда сохранить (/home/ivan/Downloads/Photos):
Источник  disk:/Photos
Файлов    390
Объём     2.6 GB
Папка     /home/ivan/Downloads/Photos
Начать скачивание? [y/n] (y):
```

Дальше показывается одна общая полоса прогресса: сколько файлов и байт уже скачано, скорость и оставшееся время:

```
⠴ Всего 38/43         ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━╸━━━━  89% 11.4/12.9 MB   31.1 MB/s 0:00:01
```

Все вопросы можно закрыть аргументами, тогда программа сработает без участия человека:

```
yadisk-dl "/Фото/25 октября" -o ~/Pictures/oktyabr --yes
```

| Параметр | Что делает |
| --- | --- |
| `path` | Путь на Диске: папка или отдельный файл. `/` означает весь Диск |
| `-o`, `--out` | Локальная папка. Структура вложенных папок сохраняется |
| `-j`, `--workers` | Сколько файлов качать одновременно, от 1 до 16. По умолчанию 6 |
| `--no-subfolders` | Скачать только файлы верхнего уровня |
| `-y`, `--yes` | Не спрашивать подтверждение перед началом |

Без терминала (cron, скрипты) нужно задать `path` и `--out`, а токен взять из `YADISK_TOKEN`. Код возврата 0 означает, что всё скачано, 1 означает, что часть файлов не скачалась или произошла ошибка API, 130 означает, что работу прервали Ctrl+C.

## Как это устроено

Программа обходит папку через `GET /v1/disk/resources`, для каждого файла запрашивает временную ссылку на загрузку и качает файл в пул потоков. Данные пишутся во временный файл `.part`. Когда файл получен целиком и его MD5 совпал с суммой от API, `.part` переименовывается в окончательное имя. Прерванная загрузка не оставит в папке обрезанный файл под настоящим именем.

При повторном запуске файл пропускается, если он уже лежит в папке и совпадает по размеру. Поэтому после обрыва связи или Ctrl+C достаточно запустить ту же команду. Ответы 429 и 5xx программа повторяет с нарастающей паузой, ошибки загрузки одного файла повторяет до четырёх раз.

## Ограничения

Программа только скачивает. Загрузки на Диск и двусторонней синхронизации в ней нет.

Время изменения файлов не восстанавливается: у скачанных файлов будет время загрузки. Публичные ссылки и корзина не поддерживаются, работа идёт по путям на вашем Диске.

Если Яндекс начнёт отвечать ошибками 429 слишком часто, уменьшите `--workers`.

## Разработка

```
pip install -e ".[dev]"
pytest
```

Тесты поднимают локальный сервер, который изображает API Диска, поэтому токен и сеть им не нужны.
